# Expense Tracker App

A Flutter Expense Tracker App to manage your income and expenses easily.

## Features
- Add income and expense with title, amount, and date
- Summary cards showing total income, total expense, and balance
- Delete expense with confirmation
- Local storage using `shared_preferences`
- Clean and professional UI using only basic Flutter widgets
- Floating buttons for quick add of income or expense
